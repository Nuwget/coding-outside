# ADR-0003 (superseded): WASM engine para Desk Apps no firmware

## Status

**Superseded** por `adr-0003-wamr-over-wasm3.md`.

## Motivo

`wasm3` está essencialmente sem manutenção desde 2020 (último release 0.5.0, issues abertas, sem WASI real). Não é uma base segura para rodar Desk Apps em produção no ESP32-S3.
